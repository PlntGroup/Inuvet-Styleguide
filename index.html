Zum Formular

System-Logik

Drei Schichten, die wir nicht mischen: System (wie etwas gebaut ist), Haut (was die Marke abweichend macht), Kühlschrank (Inhalte im jeweiligen Shop). Ein Guide für alle Marken dieser Familie — nicht ein Styleguide pro Marke.

System

planet-brands.css und planet-brands.js: Tokens, Buttons, Raster. Inuvet ist der Default in :root. Was alle Shops teilen, gehört hierher — nie in eine Marken-Datei.

Haut

Eine Datei pro Marke: brand-campus.css, brand-planimol.css. Nur Abweichungen (Tokens, Campus-Weiche, Ausnahmen). Im Theme nach dem System laden. Im Guide: Schalter Campus / Planimol.

Kühlschrank

Texte, Logos, Lotties und Benefits liegen im Shopify-Store, nicht im CSS. Logos im Guide unter assets/brands/{handle}/. Jede Marke hat ihren eigenen Store.

Themes

Ein Theme-Repo pro Shop: inuvet-theme, inuvet-campus-theme, später Planimol. Kein Marken-Schalter im Theme. Git nur nach staging.

Kein zweiter Styleguide für Planimol oder EQX — das würde das System forken. Planet-Styleguide bleibt (Gruppen-Website, anderes System). temp.css und temp.js sind leer und nur zum Testen, bevor etwas ins System wandert.
